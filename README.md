# Linguistic — লিঙ্গুইসটিক অলিম্পিয়াড প্রস্তুতি কোর্স

React + Vite ফ্রন্টএন্ড, Google Apps Script + Google Sheets ব্যাকএন্ড, Google Drive-এ ছবি সংরক্ষণ।
সেটআপ ও ডিপ্লয়মেন্টের পূর্ণ নির্দেশনা: [`README_BN.md`](./README_BN.md)

```bash
npm install
cp .env.example .env   # VITE_API_URL বসান
npm run dev            # লোকাল প্রিভিউ
npm run build          # প্রোডাকশন বিল্ড (dist/)
```
