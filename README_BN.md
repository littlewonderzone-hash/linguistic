# Linguistic — লিঙ্গুইসটিক অলিম্পিয়াড প্রস্তুতি কোর্স: চালু করার গাইড

কোনো কমান্ড-লাইন লাগবে না — শুধু ব্রাউজারে ক্লিক করেই পুরো ওয়েবসাইট লাইভ করা যায়।

> ⚠️ **এটা বাংলাবিদ থেকে সম্পূর্ণ আলাদা একটা সাইট।** নতুন Google Sheet, নতুন Apps Script,
> নতুন GitHub রিপোজিটরি ও নতুন Netlify সাইট বানাতে হবে। বাংলাবিদের Sheet/URL এখানে
> ব্যবহার করলে দুই কোর্সের রেজিস্ট্রেশন ও ফলাফল মিশে যাবে।

## এই ভার্সনে কী বদলেছে (বাংলাবিদের তুলনায়)

- সব জায়গায় নাম **Linguistic** / **লিঙ্গুইসটিক অলিম্পিয়াড প্রস্তুতি কোর্স**।
- শুধু **হোম পেইজের ডিজাইন** বদলানো হয়েছে (ভাষাবিজ্ঞানের থিম — বিভিন্ন লিপির বর্ণমালা-চার্ট, নানা ভাষার শুভেচ্ছা-ফিতা, একটা ছোট্ট ইন্টারঅ্যাক্টিভ ভাষা-ধাঁধা)। বাকি পেইজ আগের মতোই।
- **এমসিকিউ পরীক্ষা সম্পূর্ণ বাদ** — স্টুডেন্ট পোর্টাল, অ্যাডমিন প্যানেল, লাইভ পরীক্ষা, অফলাইন PDF সব জায়গা থেকে।
- **"বিভাগীয় সেরা ২০" ও বানান প্রতিযোগিতা সম্পূর্ণ বাদ** — সাইট, পোর্টাল, অ্যাডমিন প্যানেল, ব্যাকএন্ড ও অফলাইন PDF-এ এর কোনো চিহ্ন নেই।
  - **লাইভ পরীক্ষা** এখন শুধু লিখিত অংশ (২৫ মিনিট)।
  - **মেরিট তালিকা** এখন লিখিত পরীক্ষার *মূল্যায়ন শেষ হওয়া* নম্বরের উপর ভিত্তি করে (একটা পরীক্ষার সবগুলো প্রশ্নের নম্বর দেওয়া হলে তবেই তালিকায় আসে; প্রতিজন স্টুডেন্টের সর্বোচ্চ স্কোর)।
  - এমসিকিউ-ই ছিল ফ্রি নিবন্ধনের একমাত্র সুবিধা, তাই **ফ্রি নিবন্ধন অপশন ও "কোর্স কিনুন/Upgrade" পেইজও বাদ** — এখন শুধু পেমেন্ট দিয়ে নিবন্ধন।
- **"অনুধাবনমূলক পরীক্ষা"-র নাম এখন "লিখিত পরীক্ষা"** — সব জায়গায়।
- **আগে থেকে থাকা প্রশ্নগুলো নিজে নিজেই Model Test হয়ে যায়** — তৈরির ক্রম অনুযায়ী Model Test-01, 02, ... নম্বর পায় (`setup` আবার Run করলে বা অ্যাডমিন প্যানেলে প্রশ্নের তালিকা খুললেই)। আলাদা সময় দেওয়া না থাকলে সেটিংসের ডিফল্ট সময় প্রযোজ্য হয়।
- **নতুন: ছবি দিয়ে প্রশ্ন যোগ/এডিট** (অ্যাডমিন প্যানেল → "প্রশ্ন (লেখা/ছবি)" ট্যাব):
  - উদ্দীপক বা পুরো প্রশ্নের একটা ছবি, এবং/অথবা প্রতিটা প্রশ্নের আলাদা ছবি দেওয়া যায় — ক্যামেরায় ছবি তুলে বা গ্যালারি থেকে।
  - কিছু না লিখে **শুধু ছবি** দিয়েও প্রশ্ন যোগ করা যায়। ছবিতে সব প্রশ্ন থাকলে প্রশ্ন-স্লটগুলো ফাঁকা রেখে শুধু নম্বর ঠিক করে দিলেই হয়।
  - এডিটে গিয়ে ছবি বদলানো বা সরানো যায়।
  - ছবি সেভ হয় **ডেটাবেজ Google অ্যাকাউন্টের (যে অ্যাকাউন্টে Apps Script চলছে) Drive-এ**, `Linguistic Question Images` ফোল্ডারে। স্টুডেন্টরা পরীক্ষার সময়, ফলাফলে এবং অ্যাডমিন খাতা মূল্যায়নের সময় সেই ছবি দেখতে পায়। অফলাইন প্রশ্নপত্র (PDF)-এও ছবি বসে।
  - স্টুডেন্টদের জমা দেওয়া উত্তরের ছবি আগের মতোই আলাদা ফোল্ডারে (`Linguistic Written Answers`) জমা হয়।

## ধাপ ২ — Google Apps Script (API সার্ভার)

1. Sheet-এর মেনু থেকে **Extensions → Apps Script**।
2. পুরনো কোড (`function myFunction() {}`) সব মুছে `apps-script/Code.gs` ফাইলের **সম্পূর্ণ কোড** পেস্ট করুন।
3. **Save** করুন, প্রজেক্টের নাম দিন `Linguistic API`।
4. ফাংশন-ড্রপডাউন থেকে **setup** বেছে **▶ Run** চাপুন।
5. প্রথমবার **Authorization required** আসবে → **Review permissions** → আপনার অ্যাকাউন্ট → **Advanced** → **Go to Linguistic API (unsafe)** → **Allow**।
6. আবার **▶ Run** করুন। Execution log-এ "সেটআপ সম্পন্ন!" দেখবেন।
7. Sheet-এ ফিরে দেখবেন `Registrations`, `Settings`, `Admins`, `Notices`, `Contacts`, `WrittenQuestions`, `WrittenAttempts` ট্যাব তৈরি হয়ে গেছে।
   ডিফল্ট অ্যাডমিন লগইন: **Username `admin`**, **Password `linguistic2026`** — চালু হওয়ার পর `Admins` শিটে গিয়ে পাসওয়ার্ড বদলে ফেলুন।

### ওয়েব API হিসেবে পাবলিশ

8. **Deploy → New deployment** → ⚙️ থেকে **Web app**।
9. **Execute as: Me**, **Who has access: Anyone** → **Deploy** (আবার Allow করুন)।
10. যে **Web app URL** (`https://script.google.com/macros/s/xxxx/exec`) পাবেন সেটা কপি করে রাখুন।

> ⚠️ পরে `Code.gs` বদলালে: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**। নাহলে পরিবর্তন লাইভ হবে না।

## ধাপ ৩ — GitHub-এ কোড তোলা

1. [github.com](https://github.com) এ অ্যাকাউন্ট খুলুন (থাকলে লগইন)।
2. **+ → New repository** → নাম `linguistic` → **Public** → README যোগ **করবেন না** → **Create repository**।
3. **uploading an existing file** লিংকে ক্লিক করুন।
4. জিপ এক্সট্র্যাক্ট করে ভেতরের **সব ফাইল ও ফোল্ডার** ড্র্যাগ করে ছেড়ে দিন (ফোল্ডারটা নিজে নয়, ভেতরের জিনিসগুলো)।
5. আপলোড শেষে নিচে **Commit changes**।

## ধাপ ৪ — Netlify-তে হোস্ট

1. [netlify.com](https://netlify.com) → **Sign up with GitHub**।
2. **Add new site → Import an existing project → Deploy with GitHub** → `linguistic` রিপোজিটরি বাছুন।
3. Build settings: **Build command:** `npm run build` · **Publish directory:** `dist`
4. **Show advanced → New variable**:
   - Key: `VITE_API_URL`
   - Value: ধাপ ২.১০-এর Apps Script URL
5. **Deploy**। ২–৪ মিনিট পর সাইট লাইভ।
6. (ঐচ্ছিক) **Site configuration → Change site name** → `linguistic` → লিংক হবে `linguistic.netlify.app`।

> 💡 Netlify-র বিল্ড ক্রেডিট বাঁচাতে: একাধিক ফাইল বদলাতে হলে GitHub-এ সবগুলো একসাথে আপলোড করুন — তাহলে একটাই বিল্ড হবে।

## ধাপ ৫ — অ্যাডমিন প্যানেল

লিংক: `আপনার-সাইট.netlify.app/system-3212/admin-panel/login`

প্রথমে **সেটিংস** ট্যাবে কোর্স ফি, ছাড়ের ডেডলাইন, কোর্সের ছবির লিংক, লিখিত পরীক্ষার ডিফল্ট সময় (মিনিট) বসান। **লাইভ পরীক্ষা** ট্যাবে লাইভ পরীক্ষাগুলো যোগ করুন। **রেজিস্ট্রেশন** ট্যাবে বিকাশ পেমেন্ট যাচাই করে কনফার্ম/রিজেক্ট করুন।

### ছবি দিয়ে প্রশ্ন যোগ করার নিয়ম

1. **"প্রশ্ন (লেখা/ছবি)"** ট্যাব।
2. একটা প্রশ্ন-সেট = একটা Model Test। সেটে যত খুশি প্রশ্ন রাখা যায় ("+ আরেকটা প্রশ্ন যোগ করুন")। উদ্দীপকের লেখা লিখুন **অথবা/এবং** "উদ্দীপক / পুরো প্রশ্নের ছবি" ঘরে ছবি তুলুন বা আপলোড করুন।
3. প্রতিটা প্রশ্নের নিচেও আলাদা ছবি দেওয়া যায়; লেখা ফাঁকা রেখে শুধু ছবি রাখলেও হবে। প্রতিটার **নম্বর** ঠিক করুন।
4. "মডেল টেস্ট" টিক থাকলে নিচে **সময় (মিনিট)** ও চাইলে **Model Test নম্বর** দিন (নম্বর ফাঁকা রাখলে পরের নম্বর নিজে বসে)। "লাইভ টেস্ট" টিক দিলে বেছে নিন প্রশ্নটা কোন লাইভ পরীক্ষায় আসবে (বা সব লাইভ পরীক্ষায়)।
5. **ড্রাফট রাখুন** (স্টুডেন্ট দেখবে না) বা **প্রকাশ করুন**।
6. তালিকা থেকে **এডিট** চাপলে আগের ছবিসহ ফর্ম খুলবে — ✕ চেপে ছবি সরানো বা নতুন ছবি দেওয়া যায়।

## পরীক্ষা ব্যবস্থা — কী আছে

স্টুডেন্ট `/student/login`-এ ইমেইল+পাসওয়ার্ড দিয়ে ঢুকে `/student` পোর্টালে নোটিশ, ফলাফল ও পরীক্ষা দেখবে (রেজিস্ট্রেশন কনফার্মড থাকতে হবে):

- **লিখিত পরীক্ষা = Model Test সিরিজ।** স্টুডেন্ট "লিখিত পরীক্ষা" চাপলে **Model Test-01, Model Test-02, …** তালিকা আসে; যেটা খুশি বেছে নিয়ে দিতে পারে (একটা শেষ হলে পরেরটা, আগেরটা আবার দিয়ে অনুশীলনও করা যায়)। প্রতিটা মডেল টেস্টের প্রশ্ন অ্যাডমিনের ঠিক করা **নির্দিষ্ট** — র‍্যান্ডম নয়, সবার জন্য একই। সময়ও প্রশ্ন লেখার ফর্ম থেকেই প্রতিটা মডেল টেস্টের জন্য আলাদা ঠিক করা যায়। ফল জমা দিলে মূল্যায়নের পর নম্বর ও মেন্টরের দাগ পোর্টালে আসে।
- **লাইভ পরীক্ষা (একাধিক, একই দিনেও)** — প্রশ্ন নির্দিষ্ট (র‍্যান্ডম নয়): ওই লাইভ পরীক্ষায় বাঁধা সব প্রকাশিত প্রশ্ন-সেট। অ্যাডমিন "লাইভ পরীক্ষা" ট্যাবে যত খুশি লাইভ পরীক্ষা যোগ করতে পারেন (প্রতিটার নাম, শুরু/শেষের সময়, পরীক্ষার মিনিট আলাদা)। স্টুডেন্ট পোর্টালে লাইভ পরীক্ষার তালিকা দেখে (চলছে / শুরু হয়নি / শেষ / অংশ নিয়েছেন) প্রতিটায় **একবার** অংশ নিতে পারে — একটা দিয়ে শেষ হলে পরেরটা আবার ফাঁকা থাকে।
- **মেরিট তালিকা** — লাইভ (পরীক্ষা বেছে) ও Model Test (নির্দিষ্ট টেস্ট বা সবগুলোর সর্বোচ্চ নম্বরের যোগফল), মূল্যায়ন শেষ হওয়া খাতার ভিত্তিতে।

**খাতা মূল্যায়ন:** অ্যাডমিন প্যানেলের "খাতা মূল্যায়ন" ট্যাবে পেন্ডিং খাতা খুলে ছবির উপর দাগানো যায় (৫ রঙের কলম, শেপ, টেক্সট, জুম), প্রতিটা প্রশ্নের নম্বর দিয়ে সেভ করলে দাগানো ছবিসহ ফলাফল স্টুডেন্টের পোর্টালে চলে যায়। প্রশ্নের ছবিও (থাকলে) মূল্যায়নের সময় উপরে দেখা যায়।

**লাইভ ফলাফল:** "লাইভ ফলাফল" ট্যাবে লাইভ পরীক্ষা বেছে র‍্যাঙ্কিং টেবিল ও প্রিন্ট/PDF বাটন। মেরিট তালিকা পেইজেও লাইভ পরীক্ষা বেছে দেখা যায়।

**অফলাইন প্রশ্নপত্র:** "অফলাইন প্রশ্নপত্র" ট্যাব থেকে একটা নির্দিষ্ট Model Test বা সবগুলো একসাথে A4 PDF (ছবির প্রশ্ন থাকলে ছবিসহ)।
